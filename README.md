# Catalyst Clarity

Build Catalyst AI, a responsive AI-powered workplace productivity platform that helps professionals turn workplace overwhelm into clear action.

The MVP should include four core AI tools:

 Email Assistant — helps users create professional emails from their input.

 Meeting Assistant — converts meeting notes into summaries, decisions, action items, and open questions.

 Task Planner — helps users prioritise tasks and create a realistic work plan.

 Research Assistant — helps users structure research topics into insights, opportunities, risks, and next steps.

The platform should have a clean, professional dashboard where users can access these tools. It should be responsive for desktop and mobile, with a focus on clarity, productivity, and responsible AI use.
